# 02. vi / Vim

> 수업 필기 정리 · 원본: [`notes/images/p19`](../notes/images/p19_vi.jpg)

## 모드

```text
일반 모드 ──i / a / o──▶ 입력 모드
    ▲                        │
    └──────── ESC ───────────┘
일반 모드 ──:──▶ 명령행 모드 (:w, :q ...)
```

`ESC`는 습관처럼 눌러서 항상 일반 모드로 돌아오기

## 자주 쓰는 명령

| 분류 | 명령 | 의미 |
|---|---|---|
| 입력 | `i` / `a` / `o` | 지금 위치 / 한 칸 뒤 / 다음 줄에서 입력 시작 |
| 저장·종료 | `:w` | 저장 |
| | `:wq` / `ZZ` | 저장하고 종료 |
| | `:q` / `:q!` | 종료 / 저장하지 않고 강제 종료 |
| 편집 | `yy` / `p` | 한 줄 복사 / 붙여넣기 |
| | `x` / `dw` / `dd` | 한 글자 / 한 단어 / 한 줄 삭제 |
| | `u` | 되돌리기 |
| 이동·검색 | `w` | 다음 단어 첫 글자로 이동 |
| | `/Good` | "Good" 검색 |
| | `:s/expert/beginner` | 현재 줄의 expert를 beginner로 바꾸기 |
| 설정 | `:set nu` / `:set nonu` | 줄 번호 표시 / 숨기기 |
| 셸 | `:!명령` | 편집을 잠시 멈추고 셸 명령 실행 |
| | `:sh` | 셸로 잠깐 나갔다가 `exit`로 돌아오기 |

## `.vimrc`: 나만의 기본 설정

홈 디렉터리의 `~/.vimrc`에 두면 Vim을 열 때마다 자동으로 적용됩니다. → [`.vimrc`](.vimrc)

| 분류 | 설정 |
|---|---|
| 화면 | 줄 번호(`number`), 검색어 강조(`hlsearch`), 커서 위치 표시(`ruler`), 상태 표시줄 항상 표시(`laststatus=2`) |
| 검색 | 대소문자 무시(`ignorecase`), 대문자가 있으면 구분(`smartcase`) |
| 들여쓰기 | 자동 들여쓰기(`autoindent`, `cindent`), 탭 4칸(`tabstop=4`, `shiftwidth=4`), 탭을 공백으로(`expandtab`) |
| 기타 | 명령 기록 1000개, 백업 파일 만들지 않기, 문법 강조(`syntax on`) |

```bash
cp .vimrc ~/.vimrc
```
