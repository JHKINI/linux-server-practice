# 01. 셸 기본 · 파일 권한

> 수업 필기 정리 · 원본: [`notes/images/p20`](../notes/images/p20_shell_permission.jpg), [`p21`](../notes/images/p21_umask_signal_process_cron.jpg)

## 셸 기본

| 명령 / 파일 | 설명 |
|---|---|
| `history` | 지금까지 입력한 명령어 목록. `↑`는 바로 전 명령, `↓`는 최신 쪽으로 |
| 환경변수 vs 셸 변수 | 환경변수는 계속 유지되고, 셸 변수는 지금 셸에서만 유효 |
| `/etc/profile` | 모든 사용자 공통 환경 설정 |
| `/etc/bash.bashrc`, `~/.bashrc` | 전체 / 내 bash 설정 |
| `mkdir` `cd` `rm` `pwd` | 디렉터리 만들기 / 이동 / 삭제 / 현재 위치 |
| `Ctrl + C` / `Ctrl + D` | 실행 중지 / 로그아웃 |
| `ls -l` | 자세히 보기 (`ls`와 `-l` 사이 띄어쓰기 필수) |

## 파일 속성 읽기

```text
-rw-r--r--  1  root  root  223  12월 7 21:37  /etc/hosts
│└┬┘└┬┘└┬┘  │   │     │     │       │            └ 파일 경로
│ │  │  │   │   │     │     │       └ 수정 날짜
│ │  │  │   │   │     │     └ 크기
│ │  │  │   │   │     └ 그룹 이름
│ │  │  │   │   └ 소유자
│ │  │  │   └ 링크 수
│ │  │  └ 기타 사용자(o): 읽기만
│ │  └ 그룹(g): 읽기만
│ └ 소유자(u): 읽기·쓰기
└ 파일 종류 (- 일반 파일, d 디렉터리)
```

- 다른 사용자에게 쓰기나 실행 권한이 있으면 보안이 약해진다.

## chmod: 권한 바꾸기 ★

`chmod [옵션] 권한 파일` · `-R`을 붙이면 하위 디렉터리까지 모두 변경

**기호 모드**: 대상 `u`(소유자) `g`(그룹) `o`(기타) `a`(전체) + `+`(부여) / `-`(제거) + `r` `w` `x`

```bash
chmod u+x test.txt     # 소유자에게 실행 권한
chmod o+x test.txt     # 다른 사용자에게 실행 권한
chmod go-w test.txt    # 그룹·기타 사용자의 쓰기 권한 제거
```

**숫자 모드**: r=4, w=2, x=1을 더한 값 (2진수 계산)

| 권한 | 2진수 | 계산 | 숫자 |
|---|---|---|---|
| `rwx` | 111 | 4+2+1 | 7 |
| `rw-` | 110 | 4+2+0 | 6 |
| `r-x` | 101 | 4+0+1 | 5 |
| `r--` | 100 | 4+0+0 | 4 |

```bash
chmod 644 index.html   # rw-r--r--  (웹 문서에 많이 씀)
chmod 755 public_html  # rwxr-xr-x  (디렉터리)
```

## umask: 새 파일 기본 권한

```bash
umask        # 현재 값 (예: 0022)
umask -S     # 기호로 보기 (u=rwx,g=rx,o=rx)
umask 022    # 새로 만드는 파일·디렉터리에서 그룹·기타의 쓰기 권한을 뺌
```

| 대상 | 기본 최대 권한 | umask 022 적용 후 |
|---|---|---|
| 디렉터리 | 777 | 755 |
| 파일 | 666 | 644 |
